#### Crates:

- [robotxt](./robotxt/): The implementation of the robots.txt (or URL
  exclusion) protocol, following RFC 9309, with the support of the
  `crawl-delay` and `sitemap` extensions.
- [sitemapo](./sitemapo/): The implementation of the Sitemap (or URL inclusion)
  protocol with the support of text and XML sitemaps, sitemap indexes, and the
  image, video, news and `hreflang` extensions.
